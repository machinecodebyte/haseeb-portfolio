# Haseeb Ahmed Portfolio

An editorial, single-page engineering portfolio with dedicated case studies. It is built with TanStack Start, React, TypeScript, Tailwind CSS 4, GSAP, and Lenis.

All editable portfolio content lives in [src/data/portfolio.ts](src/data/portfolio.ts). The verified architecture, content-editing map, and operating guidance are in [context.md](context.md).

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Validation

```sh
npm run typecheck
npm run test
npm run lint
npm run build
```

## Production preview

```sh
npm run build
npm run preview
```
